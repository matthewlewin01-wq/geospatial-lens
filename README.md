# geospatial-lens
An agent skill for uncovering GIS-related use cases in any business issue

# Overview
The Geospatial Lens is an AI SKILL.md that helps you uncover GIS-related use cases in a business issue. You describe a situation, drop in a link, or upload a document, and it translates everyday business questions into "where" questions you can act on. It then suggests concrete ways to answer them and quietly teaches you the underlying framework as you go.

What It Does
Finds where place matters in your business problem
Turns that into a short list of plain-English "where" questions
Recommends the simplest data, tools, and methods to answer each one
Proposes concrete solution opportunities you could actually build
Suggests one clear next step to get moving

The Framework (Taught As You Go)
Every problem is viewed through six kinds of geographic questions:

Location — where are things?
Scale — how big or what shape are they?
Route — how do things move between places?
Distribution — are things spread out or clumped together?
Proximity — what's near what?
Correlation — do conditions in one place relate to conditions somewhere else?
And four modes of analysis:

Describe — what is it now?
Diagnose — why is it that way?
Predict — what's coming?
Prescribe — what should we do?
Each question you get back carries a compact tag (for example, Distribution + Describe) so you learn the framework over time without it taking over the response.

How To Use It
Describe a business problem, paste a link, or upload a document.
Add context if you have it: your goal, the regions involved, what data you already hold.
Receive a structured response with the geography in your problem, key "where" questions, solution opportunities, and a first step.
Ask for more depth on any question or solution. Responses stay short by default.

What You Get Back

Every response follows the same shape:
Overview — one short paragraph on where place matters in your problem (or an honest note if it doesn't)
Key Geospatial Questions — three to six plain-English "where" questions, each with a framework tag and a concrete way to answer it
Solution Use Cases — three to six specific solutions, including at least one agent-mediated option when it genuinely adds value
Next Step — one concrete first move, not the whole project

Modern Solution Patterns
Beyond classic dashboards and maps, it will consider agent-mediated solutions when they add value:

Conversational spatial agents that run analysis on demand from natural-language questions
Background monitoring agents that watch spatial data and alert the right people with context
Embedded spatial reasoning inside tools you already use (Teams, Outlook, CRMs, service desks)
Hybrid solutions where a dashboard serves power users and an agent serves everyone else

Good To Know
It works best when you share your goal and any constraints up front.
Responses are short by design. Ask for depth whenever you want it.
For a large or many-themed document, it will ask whether you want one overall analysis or a theme-by-theme breakdown.
